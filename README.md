# SyMirror

**SyMirror** is a Windows screen mirroring tool that allows you to display and control your Android device from your computer - similar to scrcpy but with enhanced features.

## 📥 Download

**Latest Version:** [v1.0.0](https://github.com/infoamunlocker-create/SyMirror/releases/latest)

Download the `SyMirror_v1.0.0.zip` file from the releases section.

## 🚀 Quick Start

1. **Download** the latest release zip file
2. **Extract** all files to a folder on your computer
3. **Run** `SyMirror.exe` as Administrator
4. **Enable USB Debugging** on your Android device
5. **Connect** your device via USB
6. **Start** mirroring!

## 📋 Requirements

- Windows 10 or later
- Android device (5.0+)
- USB Debugging enabled
- .NET Runtime 6.0+

## ⚠️ Important Notes

- **Keep all DLL files** in the same folder as `SyMirror.exe`
- **Run as Administrator** for proper functionality
- First launch may take a few seconds to initialize

## 🔧 Troubleshooting

If you encounter issues:
1. Make sure all files are extracted from the zip
2. Check that your device has USB Debugging enabled
3. Try running as Administrator
4. Ensure no antivirus is blocking the tool
